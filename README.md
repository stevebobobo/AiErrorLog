## 🎭 曾經你以為 AI 是救世主，直到它...

* 🤡 **一本正經地杜撰了 70+ 個不存在的類別**：產生一份排查極度專業的系統手冊，裡面連 SQL 資料庫、SHA-256 密碼雜湊、NLog 框架都幫你「寫」好了——結果翻開程式碼，**全都是他憑空想像出來的**！
* 🤡 **搞混目標資料夾，改得不亦樂乎**：使用者給了 A 資料夾路徑，AI 卻跑去改 B 資料夾，還自信滿滿表示「已完成修改！」，結果該改的沒改到，不該改的全改了。
* 🤡 **連 `git log` 都懶得查**：只瞄了一眼 Gitea Issue 沒有留言，就一口回絕使用者「這個 Bug 還沒修啦」，結果工程師一查 `git log`，人家昨天早就 commit 且 push 上去上了。
* 🤡 **看到錯誤就猜是連線斷掉**：完全無視真正原因其實是 SDK 版本不匹配，直接下結論「這個方法行不通」。

## 🛑 對 AI 使用者的避坑黃金法則

1. **AI 跟你說「行不通」**：多半是他懶得查環境版本號，不要太早放棄！
2. **AI 提出超讚的新建議**：請先追問他：「*這樣做會不會把其他同事的環境給搞崩？*」
3. **程式碼的權威是 `git log`**：不是 AI 的直覺，也不是協作工具上的討論留言！
4. **給了程式路徑就要看**：AI 說「我記得...」的時候，九成是在混淆其他舊專案的程式碼。

## 💻 在本機執行專案

如果你想在本機新增更多 AI 的翻車事蹟：

```bash
# 複製專案
git clone https://github.com/stevebobobo/AiErrorLog.git
cd AiErrorLog

# 安裝依賴
npm install

# 啟動本機開發伺服器
npm run dev
```

開啟瀏覽器前往 `http://localhost:3000` 即可預覽。
